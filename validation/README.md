# ZAFM technical validation dataset

This directory contains the **475 LUCAS 2022 reference points** used for the technical validation of the ZAFM wildfire fuel-map datasets for Spain, France, Italy, Greece and Portugal.

## Files

- `LUCAS_2022_set_validation.csv` — complete validation subset, including point coordinates, LUCAS-derived reference fuel groups, ZAFM-WCM and ZAFM-DW Scott and Burgan fuel-model assignments, broad fuel groups, temporal-stability information, and recalculated correct/incorrect flags.
- `LUCAS_2022_validation_points_shapefile/` — the same validation points as an ESRI Shapefile in **EPSG:4326 (WGS 84)**.
- `validation_summary.csv` — overall audited agreement for the two ZAFM products.

## Reference fuel groups

The validation uses five broad Scott and Burgan fuel groups:

- `NB` — non-burnable
- `GR` — grass
- `SH` — shrub
- `TU` — timber-understory
- `TL` — timber-litter

Woodland observations were manually interpreted into `TU` and `TL` using the LUCAS field photographs and the Scott and Burgan fuel-group definitions. The original photographs are **not redistributed** in this repository.

## Validation subset

The subset contains 475 spatially distributed reference points. Up to 20 points per fuel group and country were retained where sufficient eligible observations were available. Fewer non-burnable points were available for Greece and Portugal after the quality-control, land-cover, temporal-stability and valid-data filters.

All point coordinates and map assignments were audited before release. The point coordinates were checked against the original LUCAS 2022 country files, and the ZAFM-WCM and ZAFM-DW fuel-model codes were resampled directly from the published rasters. No coordinate, raster-code or broad-group discrepancies were found.

The final broad-group agreement is:

| Product | Correct / total | Overall accuracy |
| --- | ---: | ---: |
| ZAFM-WCM | 268 / 475 | 56.4% |
| ZAFM-DW | 293 / 475 | 61.7% |

The `WCM_CORRECT` and `DW_CORRECT` fields in the CSV, and `WCM_MATCH` and `DW_MATCH` in the shapefile, are defined by direct equality between the LUCAS reference group and the corresponding ZAFM broad fuel group.

## Data sources

### LUCAS 2022

The validation subset is derived from the **LUCAS 2022** survey data provided by the European Commission, Eurostat:

https://ec.europa.eu/eurostat/web/lucas/database/2022

The original LUCAS 2022 microdata and associated field photographs can be obtained from Eurostat. The photographs were used only to support the manual interpretation of woodland reference points and are not redistributed here.

Source attribution: **European Commission, Eurostat, LUCAS 2022**.

This repository contains a derived and modified subset and is **not an official Eurostat product**. Users should consult Eurostat's copyright and reuse notice:

https://ec.europa.eu/eurostat/help/copyright-notice


## Notes on reuse

The LUCAS-derived records in this directory have been filtered and supplemented with fuel-group labels and ZAFM map assignments generated by the authors. Any reuse should acknowledge the original LUCAS 2022 source as well as the relevant ZAFM dataset release. The original LUCAS photographs are not included in this package.
